# Rule-Based AI Chatbot

A simple Python-based rule-driven chatbot that identifies user queries using
keyword and pattern matching and provides appropriate predefined responses.

This project was developed as part of an Artificial Intelligence internship
task to understand the fundamentals of chatbot development, Natural Language
Processing (NLP), intent identification, and conversational flow.

---

## 📌 Project Overview

The Rule-Based AI Chatbot uses predefined rules to understand basic user
queries and respond accordingly.

Instead of using a Machine Learning model or Large Language Model (LLM),
the chatbot uses Python conditional statements, keyword matching, and
pattern-based rules.

### Basic workflow

User Input  
↓  
Text Normalization  
↓  
Keyword / Pattern Matching  
↓  
Intent Identification  
↓  
Predefined Response  
↓  
Bot Response
